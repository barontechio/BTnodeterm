Server Edition brings canvas geometry and board automation, headless agent teams and reviews, owner confirmations, and managed Codex accounts to the browser. Worktrees gain guarded creation, recovery and clean removal; optional SSH adds remote projects, files, Git, histories, context meters and streamed transfers. Browser content includes images, audio/video, isolated HTML and optional development previews, alongside browser team joins and conversation search. Optional closed-page Web Push adds generic finished-turn and needs-response notices after explicit enrollment; it is off until the operator configures HTTPS, VAPID contact and approved providers, and actual provider/OS/device delivery still requires acceptance. This fork also includes upstream changes after v0.5.0: announcement images and omission of missing images, Notch recency/hover improvements, and navigation of paths beginning with `~`.
